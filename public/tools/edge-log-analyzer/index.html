Describe what you want in plain English — this runs entirely in your browser via a small pattern-matcher (no AI, no API calls, nothing leaves your machine). It recognizes every documented r-line and f-line column by name (e.g. "object status information", "turnaround time", "forward hostname") or by number ("field 16", "column 24"), and shows you the exact AWK command it built, which you can edit directly below. Mention "f line" / "origin leg" / "upstream" to query origin/forward-leg records instead of client-facing ones. Full column reference: download the field list (PDF).

Advanced: write AWK + pipeline directly

Supports $1…$N, $0, $NF, NR, NF, == != ~ !~ < <= > >= && || !, string concatenation, and print. Pipe into sort [-n -r -u], uniq [-c], head/tail [-N], grep [-v -i] PATTERN, or wc -l. Field numbers follow the documented r-line / f-line column layout (1-indexed) — e.g. on r-lines $14=status, $16=object status information; on f-lines $15=status, $24=forward hostname.
